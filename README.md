# Проработка вторичных выгод

Практика курса Татьяны Хавро «Масштаб». Три вопроса, к каждому свой проговор. Места, где нужно подставить свои слова, выделены рамкой, паузы «Вдох-выдох» стоят отдельной строкой. Можно выбрать «Она» или «Он», и слова вроде «свободен/на» станут в нужном роде. Отметки «Проговорено» хранятся на телефоне, сайт работает без интернета и ставится на главный экран.

## Файлы

Все файлы лежат в корне репозитория, без папок:

- `index.html` — сама практика
- `manifest.webmanifest` — данные для установки на телефон
- `sw.js` — работа без интернета
- `.nojekyll`, `.github/workflows/pages-mirror.yml` — зеркало на GitHub Pages
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконки

## Как опубликовать

1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите этот репозиторий и нажмите **Import**.
3. Ничего не меняйте и нажмите **Deploy**.

После каждого изменения в репозитории Vercel сам обновит сайт примерно за минуту.

## Зеркало на GitHub Pages

У сайта два адреса с одинаковым содержимым:

- **Vercel:** https://vygody-eight.vercel.app/
- **GitHub Pages (зеркало):** https://anna3005-droid.github.io/Vygody/

Зеркало нужно тем, у кого не открывается адрес на vercel.app: у части мобильных операторов в России, Турции, Бангладеш и других странах адреса Vercel недоступны, а GitHub Pages открывается. Ничего отдельно обновлять не нужно: после каждого изменения основной ветки файл `.github/workflows/pages-mirror.yml` сам копирует её в ветку `gh-pages`, и через пару минут зеркало обновляется. Ветку `gh-pages` руками не трогайте.

## Как поставить на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → **Добавить на главный экран**.
- **iPhone (Safari):** откройте сайт → кнопка **Поделиться** → **На экран «Домой»**.

## Если поменяли файлы

В `sw.js` увеличьте номер в строке `var VERSION = PREFIX + 'v2';` (например, на `'v3'`). Тогда телефоны получат новую версию, а не сохранённую старую.
